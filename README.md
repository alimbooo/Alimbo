# سایت پورتفولیو آرمان

یک پورتفولیوی شخصی و کاملاً استاتیک با Next.js و TypeScript.

## پیش نیاز
1. نصب [git](https://git-scm.com/)
2. نصب [nude.js](https://nodejs.org/en/download)
3. اکانت [GitHub](https://github.com/)

<br>

## آموزش استفاده

### گام اول: دانلود

1. در صفحه همین ریپازیتوری روی **Use this template** کلیک کنید.
2. گزینه **Create a new repository** را انتخاب کنید.
3. یک نام برای ریپازیتوری خود انتخاب کرده و روی **Create repository** کلیک کنید.
4. پس از ساخت ریپازیتوری، روی دکمه سبز رنگ Code کلیک کنید، آدرس HTTP را کپی کنید
5. سپس در ترمینال سیستم خود دستور git clone را همراه با آن آدرس اجرا کنید تا ریپازیتوری روی سیستم شما دانلود شود.



### گام دوم: نصب
برای نصب و راه‌اندازی پروژه، مراحل زیر را انجام دهید:

1. روی فایل setup.bat کلیک کنید.
2. یک پنجره برای ورود به GitHub باز می‌شود. از طریق مرورگر وارد حساب GitHub خود شوید.
3. پس از ورود، به پنجره CMD برگردید.
4. نام کاربری و ایمیل حساب GitHub خود را وارد کنید.
5. در ادامه، وابستگی‌های موردنیاز پروژه به‌صورت خودکار نصب می‌شوند.

پس از اتمام مراحل، نصب کامل است. 

### گام سوم: ویرایش
اکنون می‌توانید فایل `admin-panel.bat` را اجرا کرده و پنل مدیریت را باز کنید.
از طریق پنل مدیریت می‌توانید تمامی موارد سایت را کترل کنید:
- برگه ها
- پروژه ها
- دسته بندی ها
- رسانه ها
- تنظیمات

برای مشاهده سایت میتوانید از گزینه پیش نمایش استفاده کنید.

### گام چهارم: انتشار

1. ابتدا به ریپوی گیت‌هاب خود بروید.
   * وارد بخش `Settings` شوید.
   * به بخش `Pages` بروید.
   * در قسمت `Source`، گزینه `GitHub Actions` را انتخاب کنید.
   * اگر از دامنه سفارشی استفاده می‌کنید، دامنه خود را در فیلد `Custom domain` وارد کنید.
2. به پنل مدیریت سایت بروید و وارد بخش `انتشار` شوید.
3. آدرس سایت را تنظیم کنید: اگر از دامنه سفارشی استفاده کردید دامنه خود را وارد کنید. اگر نکردید آدرس پیشفرض گیت هاب را وارد کنید.
4. در سایدبار، تغییراتی که در سایت ایجاد کرده‌اید بررسی و نمایش داده می‌شوند. برای ارسال تغییرات به گیت‌هاب روی دکمه `انتشار` کلیک کنید. ممکن است برای ورود به حساب گیت‌هاب، مجدداً پنجره لاگین نمایش داده شود.
5. پس از موفقیت‌آمیز بودن انتشار، به ریپوی گیت‌هاب بروید و در بخش `Actions` وضعیت اجرای اکشن را بررسی کنید. پس از تکمیل، باید تیک سبز نمایش داده شود.
6. در کارت `Deploy`، آدرس سایت نمایش داده می‌شود. روی آن کلیک کنید تا سایت را مشاهده کنید.

## بروزرسانی

برای دریافت آخرین تغییرات تمپلیت، از گزینه `بروزرسانی` استفاده کنید.

این بروزرسانی فقط کدهای اصلی سایت را دریافت می‌کند و فایل‌های شخصی شما، مانند تنظیمات، پروژه‌ها، پست‌ها و سایر محتواها، تغییر نمی‌کنند.

با این وجود، توصیه می‌شود قبل از انجام بروزرسانی از فایل‌های خود Backup بگیرید.
